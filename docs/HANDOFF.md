## 1. Product framing and the owner's standing rules

"This is a game, we will just be placing the road in the open world and I expect it to then with only that be what you'll be comparing to the images. So all the stuff has to come from the existing world and the road edge scatter." (Round 35)

- **Nothing is hand-dressed in look-test levels.** Everything in a picture comes from (a) a `world_cover` layer (ground and vegetation; seeded default, replaceable by a future world generator; pattern measured from the aerial references) or (b) road-generated content: surface, markings, kerbs, earthworks, verge and edge scatter, lighting columns. Placing a road clears world cover in its corridor. A small world (a few km) is fine for prototyping. Lighting columns ARE generated and judged (overrides the old reviewer ignore-list entry). Reviewers ignore buildings, fences/walls not generated by the road, signs, vehicles, people, other furniture (`docs/research/vegetation-plan.md`).
- **Reference photos are the target, all the time, and are opened BEFORE building.** "All the time you should be using reference images, this is at the end of the day what I want it to look like." Builders (not only reviewers) open at least 3 per case, top-down for layout, write measurements in lane widths, name the files, say where no photo covers a case, render at the same framing and compare item by item. Layout/markings are scored separately from look. Trigger: the owner found five junction faults in a minute that two rounds of "7/10" had missed ("You've got so many references how are you making these mistakes still").
- **Reference-photo downloads are pre-approved** (in chat, 11 Oct: "If you ever need more reference images go get them"; "yes please allow them to download photos as and when needed"). Reference images only, into `docs/reference/{aerial,street,gsv}/` (private, gitignored), logged in the INDEX with source URL. Assets, models, textures, tools and anything paid still need the owner. Wording is in `CLAUDE.md` because an agent once refused a relayed approval.
- **Nothing fails silently.** An agent that skips, refuses or cannot do part of its brief says so in the FIRST lines of its report and its `STATUS.md`; the main session reads STATUS files for such lines and raises them at once (owner: "im annoyed you let that fail silently").
- **The browser prototype's UI is the spec for the game's UI.** "remember a lot of these features were in the initial html, that ui was sort of what i want, that was the point of it". Port it (`docs/unreal-ui-parity.md`); outside products are only a source of extras. Known dislike: ending a road had no cue (fix in the port: click last point, Enter or right-click finishes).
- **The owner will not open the Unreal editor or playtest.** "i will never open it, this takes too long. just mess around with it yourself to test it (ideally in an agent)". Agents launch, drive (MCP over HTTP, `-game` runs, scripted input) and screenshot it, judge the result and close it. Never plan a step that needs the owner to operate Unreal. A milestone is not done until an agent has exercised the interaction.
- **The main session is the last gate on visible claims.** When an agent says a visible result is good or fixed, the main session opens the headline images itself, and asks the open question "what here would a driver or road engineer say is wrong or would never be built?" before anything goes to the owner. Unexplained planes, ramps, stripes and holes are faults. (Owner: "i don't like how i have to keep pointing this stuff out to you".) Faults go back to the agent first.
- **Videos in the browser pane must be muted** (mute immediately after navigation, close the tab after).
- **Priority #1 (unchanged):** "build in such a way that when we do the rest of the city builder it doesn't become a mess". Structure before features (`docs/unreal-architecture.md`).
- Decision split: road-engineering details are the assistant's (region-data defaults, toggles); product direction, scope, purchases, downloads (other than reference photos) and irreversibles are the owner's.
- **OPEN product question for the owner:** should the starting world contain anything man-made (lanes, farm tracks, farmsteads) before the player draws a road? The aerials show a lane and a farmstead in most views. Coordinator's recommendation: no real roads in the starting world; tracks and farmsteads come later as cover. Not decided.

## 10. How to run agents on this project

- **Unreal is a single lane**: one editor or `-game` process at a time on this 15 GB machine. But Unreal code can be written and COMPILED in a separate worktree while another agent runs the editor. Nobody kills compiler processes that are not theirs. Prefer the live editor via MCP (HTTP) over cold-start scripts (about 1 minute each).
- **Own worktree and branch per code agent**, own build dir, CLEAN builds. Merge one at a time (§8). After an agent says "N/N pass" in a shared tree, trust only a clean build of the merged state.
- **Method and photos settled before building.** If tuning stalls after one round, change the method rather than tuning a second time (the Voronoi fields and stacked terraces both ate rounds).
- **Fresh agent per round, starting from a STATUS file; resume an agent only for short follow-ups.** Give fewer, larger tasks. Point briefs at the exact files and functions. Pass the owner's words verbatim (agents trust quotes in `CLAUDE.md` over relays).
- **Agents open their own renders before reporting** and put skipped / refused / unverified items FIRST in the report and in STATUS.md. The main session reads STATUS files, not only final reports, and opens the headline images itself (§1).
- **Reviews:** downscaled images and possibly a cheaper model; briefs require the files opened listed, at least 3 photos per view, the open "what would never be built?" question, and separate scores for layout/markings and look.
- **Watch the usage limit:** at most 3-4 agents at once, finish before starting more, stop agents re-sending finished reports, commit WIP to a branch before the limit. Observed: 02:40 and about 12:40 on 11 Oct, both cut agents off mid-edit.
