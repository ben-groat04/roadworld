# Test world previews (11 Oct 2026)

Generated by `tests/test_world.cpp` (case "previews"), then recompressed with `tests/tools/png_recompress.mjs`:

    CP_WORLD_PREVIEW_DIR=docs/progress/2026-10-11-test-world build/tests/sim_core_tests -tc="test_world*"
    node tests/tools/png_recompress.mjs docs/progress/2026-10-11-test-world

Each seed (1, 2, 3), 2048 m square, top-down images at 2 m per pixel, north up. Default `TestWorldParams`; cover from the uk
region pack (default cover source wrapped by the terrain-aware one). Seeds differ in valley position, meander, which side the
scarp is on and where along the valley it lies.

| File | What |
|---|---|
| `seedN_hillshade_contours.png` | Hillshade (NW light) with hypsometric tint; contours every 5 m, heavier every 25 m |
| `seedN_slope.png` | Slope classes: pale <3 %, green <6 %, yellow <12 %, orange <20 %, red <30 %, purple >=30 % |
| `seedN_cover.png` | Ground cover class over hillshade (dark green woodland, light green pasture, tan arable, olive rough/wet), hedge lines (dark lines), tree dots |
| `seedN_oblique_valley.png` | Ray-marched view up the valley from its low end; the wet/rough strip follows the valley line |
| `seedN_oblique_scarp.png` | View across the valley at the steep side (woodland hanger on the scarp) |
| `seedN_oblique_overview.png` | High corner view of the whole world |

Oblique views are flat-coloured ground classes only (no tree meshes): a terrain check, not a realism render.
The rectilinear field grid is the existing default cover generator (not changed here).
