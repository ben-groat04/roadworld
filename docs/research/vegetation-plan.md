Research note, 11 Oct 2026. Tags: [V] read in a primary source or opened image/file this pass; [U] unverified (search snippet, inference); [E] my estimate from images (rough, scale by eye from lane/road width, 1 lane about 3.0-3.65 m, single-track about 3.5 m, UK A-road about 7.3 m). Counts below are "of the 36 images opened", rounded by eye. Product framing (from the person): a road placed in an open world. A picture can only contain (1) WORLD cover that exists before the road, (2) ROAD-EDGE scatter created by the road, and (3) CUT-EDGE: world cover truncated by the road corridor. No hand dressing.

**Reviewer lists (reusable).** Ignore: buildings, fences/walls not generated by the road, signs, vehicles, people, lighting columns and other street furniture, utility poles/pylons, railways and water, bins/shelters. ## Part 3. Getting assets free today

### 3a. Unreal Procedural Vegetation Editor (PVE)
- Plugin `ProceduralVegetationEditor` in `C:\UE_5.8\Engine\Plugins\Experimental\ProceduralVegetationEditor\ProceduralVegetationEditor.uplugin`: FriendlyName "Procedural Vegetation Editor", IsExperimentalVersion true, IsBetaVersion false, EnabledByDefault false, CanContainContent true [V]. Modules: `ProceduralVegetation` Runtime (PostConfigInit) and `ProceduralVegetationEditor` Editor, platform allow-list Win64/Linux/Mac. Dependencies: Dataflow, GeometryScripting, PCG, DynamicWind (DynamicWind is "extremely experimental") [V].
- Content shipped: `Content/SampleAssets/StarterContent` with DeciduousTree_01, ConiferTree_01, Deciduous_Shrub_01, Plant_01 and 10 grower presets (Leaf_Tree_01-04, Pine_01, Sapling_01, Shrub_01, Spruce_01/02, Tropical_01); species growth data JSON for Common Hazel, European Beech, European Quaking Aspen, Norway Maple; `Maps/Asset_Zoo.umap`; wind settings; PCG sample `Wind_Example_PCG` [V, file listing]. Hazel, beech, aspen and maple fit UK broadleaf.
- Output: Epic docs say the Export node bakes a Nanite asset using Nanite Foliage (assemblies, GPU skeletal-driven animation, voxelised distant representation) and can export a standard static mesh; wind data via Dynamic Wind [V, Epic docs page]. 5.7 PVE assets do not open in 5.8; the preset loader was removed [V docs; search summary].
- Automation: no Python entry points seen in the plugin source (only a few UFUNCTIONs on data assets), and no vegetation toolset under `Plugins\Experimental\Toolsets` (PCGToolset only edits PCG graphs) [V]. So building trees is GUI node-graph work in the editor; driving it from MCP or Python is [U] and not expected.
- Packaged builds: forum thread "Procedural Vegetation Nanite Foliage meshes crash packaged project": packaged 5.8 and 5.8.1 crash at load with PVE/Megaplants Nanite Foliage meshes (assertion in RawIndexBuffer.h from FPVLightDetection::BuildLeafMeshGeometry); ticket UE-386321 reported closed "Fixed" with target 5.8.2 [V, forum; fix itself not confirmed by Epic staff in the excerpt]. We have 5.8.3 so likely fixed [U]: the packaged-build test below is mandatory.

### 3b. Nanite Foliage in 5.8
Project setting "Nanite Foliage (Experimental)" (`r.Nanite.Foliage`, "Enables experimental features required to support Nanite Foliage") in `RendererSettings.h` [V]. Epic roadmap and docs still call both PVE and Nanite Foliage experimental in 5.8 [V, search results]. Plugins `NaniteAssemblyEditorUtils` and `PCGNaniteAssembliesInterop` are experimental editor-only modules [V]. Verdict: use as an option, with masked-card fallback.

### 3c. PCG GPU scatter on our own surface
PCG plugin 1.0 (not beta flag) [V]. GPU-capable elements in the headers: Copy Points, Transform Points, World Raycast, Static Mesh Spawner, Skinned Mesh Spawner, Normal To Density, Cull Points Outside Actor Bounds, Custom HLSL [V]. `UPCGProceduralISMComponent`: "instance data must be written direct to the GPU scene" [V]. A Surface Sampler is not on the GPU list; points must come from CPU or from a GPU-capable source, then project with World Raycast against traceable geometry (our runtime mesh component supports ray tracing, not Nanite) [U]. Whether C++ can feed arbitrary point lists straight into a GPU graph is not confirmed [U]. Because our sim already emits instance lists per tile, the fastest route skips PCG: C++ adds transforms to ISM components directly. PCG GPU is only needed if grass counts overrun that.

### 3d. Free asset sources
- **Fab:** Standard licence permits commercial use [V per Epic forum, 2024 era]. Free items rotate in drops; I did not find a stable list of free trees/hedges/grass [U]. Megascans: majority paid since 2025; about 1,500 free assets remain per Quixel's page [V search summary]; assets from the old library carry Unreal-only terms [U]. Check each listing's licence line. Verdict: opportunistic only.
- **Epic sample content:** usable commercially inside Unreal projects, not outside the engine, not resold as assets [V search summary of older Epic answers; confirm current EULA]. The PVE starter content above is the most direct source. City Sample/Electric Dreams/Valley of the Ancient foliage: reusable under the same terms but needs large downloads [U].
- **Poly Haven (CC0):** API lists 57 plant-category models [V, api.polyhaven.com]. Usable for us: `grass_medium_02`, `weed_plant_02`, `nettle_plant`, `dandelion_01`, `celandine_01`, `periwinkle_plant`, `shrub_01`..`shrub_04`, `shrub_sorrel_01`, `fern_02`, `tree_small_02` (broadleaf), `fir_tree_01`, `fir_sapling`, `fir_sapling_medium`, `pine_tree_01`, `pine_sapling_small/medium`, `moss_01`. No hedge, no mature oak/ash. Many are South African karoo plants (ignore). Verdict: grass, weeds, shrubs and conifers free and safe.
- **Blender generators:** Sapling Tree Gen 0.3.7 (GPL v3+, free, not geometry nodes, targets 4.4+) is listed as working in 4.5 but reviews report failures in 5.0.1 and 5.1 [V, extensions.blender.org snippets]. Our kit pipeline tests Blender 5.2.2, so Sapling is risky. Geometry-nodes options "Easy Tree" and "Modular Tree" exist; licences and 5.x status not checked [U]. Infinigen: BSD, Windows experimental, trees export poorly (see `vegetation-and-surface-realism.md`). A self-written hedge/scrub/grass generator in `tools/blender_kit/` (cards and cluster meshes, with licensing clear) is feasible: effort 2-3 days for hedge and grass, trees weak.

### 3e. Verdicts and recommended mix (free first)
1. **Trees:** PVE (Hazel, Beech, Maple, Aspen, Deciduous_01 presets; maple/beech as oak stand-ins) exported as static mesh with Nanite + card leaves, plus bare versions from the same skeleton; packaged-build test first. Fallback: Poly Haven `tree_small_02` plus Blender-built cards. Free.
2. **Hedges:** build in Blender kit (box mesh with cluster leaf cards, 2 styles); free, in-house.
3. **Grass, weeds, shrubs, conifers:** Poly Haven CC0 (convert to cards). Free.
4. **Distant woodland:** bake impostors from our own trees in the editor. Free.
5. **Cost:** none required. Optional Fab buys only if the hedge step fails; flag any.

## Part 4. Ordered tasks (agent-sized, file ownership)

Placement contract (sim agent exposes; kit agrees). Instance record: `type_id` (string), world position (double), yaw, uniform scale, tilt, `variant` (uint8), `seed`, `tint` (0-1 hue/health), `leaf_state` (leaf/bare/budding), `layer` (world_cover | road_edge | cut_edge), tile key.

**world_cover type ids and parameters** (above table): `tree_broadleaf_round`, `tree_broadleaf_open`, `tree_conifer_plantation`, `tree_sapling_staked`, `hedge_trimmed`, `hedge_overgrown`, `shrub_scrub`, `shrub_gorse`, `grass_rough_tuft`, `grass_tussock`, `bracken_patch`, `canopy_impostor_block`. Params: cover_class per cell (pasture, arable, rough, woodland, scrub, parkland), field_long/short_m, field_aspect, boundary_hedge_share, hedge_width_m, hedge_height_m, hedge_tree_prob, hedge_tree_spacing_m, hedge_gap_per_km, woodland_share, woodland_block_m, woodland_edge_amplitude_m, scattered_trees_per_ha, season (leaf_state), seed. Seam: `WorldCoverSource` interface returning cell classes and boundary polylines.

**road_edge type ids and parameters:** `grass_mown_clump`, `grass_rough_tuft`, `weed_creep`, `shrub_scrub`, `shrub_gorse`, `tree_sapling_staked`, `tree_broadleaf_*`, `hedge_trimmed` (lane hedges). Params: verge_mown_width_m (1-5), verge_rough_width_m (1-4), edge_creep_width_m (0.1-0.3), edge_creep_density, bank_scrub_density, centre_reservation_grass_height_m (0.4-0.8), island_grass (mown), corridor_belt_width_m and density (dual: 15-40), sapling_row_spacing_m (2-4), cover_clear_margin_m (1.5 hard), blend_band_m (6-10, thinning curve; hedge cut end: `cut_face` true, no blend), junction_clearance_m (20-50).

Tasks:
1. **Sim, placement layers** (owner: sim agent, `sim_core/src/vegetation_*`, `data/regions/uk/vegetation.json`): implement the contract; golden tests; no Unreal deps.
2. **Asset: hedge and grass generator** (Blender agent, `tools/blender_kit/vegetation.py`, `params.py`, manifest): trimmed and overgrown hedge modules, grass tufts/tussock, scrub clump, weed strip, FBX + manifest. Needs Blender, no editor.
3. **Asset: PVE trees** (needs editor, one human or editor-capable agent session): enable plugin, build 3 broadleaf + 1 conifer + bare variants, export static mesh/Nanite, save in `unreal/CityPainter/Content/Vegetation/`.
4. **Poly Haven conversion** (Blender agent): grass, weed, shrub, conifer cards from approved downloads.
5. **Unreal import and instancing** (Unreal agent, `unreal/CityPainter/Source/`): map `type_id` to meshes via data asset; ISM components per tile and type; start small test world of a few km.
6. **LOD, wind, impostors and performance check** (Unreal agent): LOD chains, WPO cut-off, impostors, tree count 50K, grass under 30 m; measure on 3060.
7. **Packaged-build test** (human or agent with build rights): cook Win64 with PVE assets and Nanite Foliage on; confirm no crash from UE-386321.
8. **Review**: cold-read Sonnet with the Part 2 reviewer lists against the 36 images.

**Downloads needing approval** (do not fetch without a yes):
- Poly Haven CC0 models (via https://polyhaven.com or the Blender MCP search_assets): grass_medium_02, weed_plant_02, nettle_plant, dandelion_01, celandine_01, shrub_01..04, fir_tree_01, pine_tree_01, tree_small_02, moss_01. Sizes not verified, likely tens of MB each.
- None for PVE: all content ships in `C:\UE_5.8`.
- Optional: Fab free items (none selected); Blender add-ons Easy Tree / Modular Tree from extensions.blender.org (licences unchecked).

Editor needed for: tasks 3, 5 (mesh settings), 6 and 7. Blender-only: 2, 4. Sim-only: 1.
